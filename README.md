# oneliner3-funniest-out-of-office

What happens when the person who owns the inbox goes away for the weekend? In this reply, the replacement is already on the job — four legs, zero inbox-zero discipline, and somehow a promotion before Monday.

Running `main.ts` produces the one-line entry in `/output/entry.txt`:

> I'm out of office until Monday. My dog is covering my inbox — he's replied to everyone with 'good boy' and already been promoted.

## How to run it

    node main.ts

When `$MAKEFUN_OUTPUT_DIR` is set the file lands there as well; otherwise it goes to `/output/entry.txt`. The entry is exactly one line of 129 characters, no trailing newline, so it passes the bounty gate (1–140 characters).
